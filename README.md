# 배움길 정보 수업 도우미

학생용 학습 대화 화면과 교사용 실시간 모니터링 화면을 포함한 웹 앱입니다.

## 실행하기

1. Node.js 18 이상을 설치합니다.
2. 이 폴더에서 `npm start`를 실행합니다.
3. 브라우저에서 `http://localhost:3000`을 엽니다.

별도 패키지 설치는 필요하지 않습니다. 학생과 교사는 같은 서버 주소로 접속해야 질문과 진행 상황을 공유할 수 있습니다.

## 교사 접속

현재 시제품 교사 비밀번호는 `info2026`입니다. 교사 인증은 시제품용이며, 실제 수업에서 사용하기 전에는 안전한 계정 인증으로 바꿔야 합니다.

## 데이터 안내

실시간 학생 접속·대화 현황은 서버 메모리에 임시 보관됩니다. 서버가 다시 시작되면 해당 기록은 지워집니다. 실제 운영에서는 학교 정책에 맞는 인증, 데이터베이스, 기록 보관 기간을 설정해 주세요.

활동지 파일은 현재 파일 이름만 기록하며 문서 내용은 읽지 않습니다. `/__preview-bridge.js`는 미리보기 편집기 연동용 파일이며 일반 웹 서버 기능에는 필요하지 않습니다.
